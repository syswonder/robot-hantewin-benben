# tour_guide — 导览

先调用导航到area坐标, (x,y)坐标不要重试, yaw坐标要精确到0.05, 再调用`introduce(area=<区域名>)` 返回 `narration`, 调用扬声器原样播报即可.

## 流程

一次一个区域, 走到并讲完再下一个:

1. 导航到该区域的坐标, 等到达后再继续.
2. 调 `introduce(area=<区域名>)`, 把返回的 `narration` 原样念给用户, 不改写、不合并.
3. 念完通知 pilot 问用户: 还有其他问题, 还是前往别的区域.
4. 用户提问 → 答完回 3; 换区域 → 回 1; 结束 → 收尾.

## 约束

- **一次只处理一个区域**, 不要在一个回合里连发多个调用.
- 顺序默认按上表; 用户指定区域就听用户的, 未到的区域记下来, 不重复、不遗漏.
- 两个工具都没有持久化状态, 也没有游标: 未到的区域清单由**你自己**维护.
